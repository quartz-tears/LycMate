## 2. Заказчик или целевая аудитория
Основная целевая аудитория LycMate — учащиеся Лицея НИУ ВШЭ.
Можно выделить три группы пользователей:

1. **Лицеисты, которые хотят найти новых друзей.** Те, кто хочет познакомиться с ребятами из других классов и направлений.
2. **Лицеисты, ищущие напарников для учёбы и олимпиад.** Те, кому важно найти людей с похожими учебными интересами и целями.
3. **Лицеисты, ищущие компанию для мероприятий.** Например, пару на БЗС или людей для совместного посещения лицейских событий.

Все три группы смогут пользоваться одним сайтом, выбирая подходящую цель поиска.
## 3. Аппаратные и программные требования
**Аппаратные требования:**
Компьютер, ноутбук, планшет или смартфон с доступом в интернет

**Программные требования:**
- Современный веб-браузер: Google Chrome, Safari и тп.
- Поддержка JavaScript и файлов cookie в браузере.

LycMate будет веб-сайтом с адаптивным интерфейсом, поэтому им можно будет пользоваться как с компьютера, так и со смартфона
## 4. Функциональные требования
### 4.1. Лобачева Варвара — аккаунты, профили и взаимодействие пользователей

1. **Регистрация.** Пользователь может создать аккаунт с помощью корпоративной почты НИУ ВШЭ.
2. **Авторизация.** Пользователь может войти в свой аккаунт и выйти из него.
3. **Управление профилем.** Пользователь может создать, редактировать и просматривать свою анкету.
4. **Просмотр анкет.** Пользователь может открыть профиль другого лицеиста и посмотреть доступную информацию о нём.
5. **Настройки приватности.** Пользователь может изменять видимость своего профиля и контактных данных.
6. **Система симпатий.** Пользователь может поставить или убрать лайк на анкете другого лицеиста.
7. **Взаимные совпадения.** Пользователь может просматривать список взаимных симпатий и получать доступ к контактам при совпадении.
8. **Блокировки и жалобы.** Пользователь может заблокировать другого лицеиста или отправить жалобу на его профиль.
9. **Модерация.** Пользователь с правами модератора может просматривать жалобы и ограничивать доступ нарушителей.

### 4.2. Гусева Лидия - Кристина — поиск, рекомендации и подбор напарников

1. **Выбор цели поиска.** Пользователь может выбрать, кого он ищет: друга, пару на БЗС, напарника для учёбы или олимпиады, компанию на мероприятие.
2. **Многофакторный поиск.** Пользователь может искать лицеистов по интересам, направлению обучения, классу и другим параметрам.
3. **Персонализированные рекомендации.** Пользователь может получать список анкет, отсортированных по степени совместимости.
4. **Настройка рекомендаций.** Пользователь может менять важность критериев поиска и просматривать причины рекомендаций.
5. **Создание объявлений.** Пользователь может публиковать объявления о поиске напарников с указанием цели и описания.
6. **Поиск объявлений.** Пользователь может просматривать и фильтровать объявления других лицеистов.
7. **Отклики на объявления.** Пользователь может отправлять отклики на объявления и отзывать их.
8. **Управление объявлениями и откликами.** Пользователь может редактировать и закрывать свои объявления, а также принимать или отклонять полученные отклики.
9. **Сохранение поисковых данных.** Пользователь может сохранять и повторно загружать настройки поиска, а также экспортировать собственные объявления.
## 5. Похожие или аналогичные продукты
**1. Бибинто**

Телеграм-бот, в котором пользователи могут оценивать фотографии друг друга, знакомиться и находить новых собеседников. Основной акцент сделан на внешности и взаимной симпатии.

Недостаток для нашей целевой аудитории — отсутствие привязки к конкретному учебному заведению. Кроме того, сервис не предназначен для поиска напарников по учебным предметам, олимпиадам и лицейским мероприятиям.

**2. Дайвинчик**

Бот для знакомств, в котором пользователи создают анкеты, просматривают профили других людей и ставят лайки. При взаимной симпатии они могут начать общение.

Главный недостаток — широкая аудитория, среди которой могут оказаться люди разного возраста и из разных городов. Возраст и принадлежность к определённому учебному заведению не подтверждаются так, как это планируется в LycMate. Также поиск не ориентирован на конкретные задачи лицеистов.

**Преимущества LycMate перед аналогами**

- **Ограниченная аудитория.** Зарегистрироваться смогут только учащиеся Лицея НИУ ВШЭ через подтверждение корпоративной почты.
- **Поиск среди лицеистов.** Пользователи будут знакомиться с людьми из своего учебного заведения, в том числе из других классов и направлений.
- **Поиск по конкретной цели.** Можно будет отдельно искать друзей, пару на БЗС, напарников для учёбы и олимпиад или компанию на мероприятия.
- **Более подробные фильтры.** При подборе будут учитываться интересы, направление обучения, учебные предметы и другие параметры.

Таким образом, LycMate будет не просто сервисом знакомств, а платформой для поиска людей внутри лицейского сообщества с учётом целей и интересов пользователей.
## 6. Инструменты разработки и база данных

Для разработки LycMate мы планируем использовать следующие технологии:

1. **Python** — основной язык программирования для серверной части сайта, обработки данных и реализации алгоритма рекомендаций.
2. **Django** — веб-фреймворк на Python, с помощью которого будут реализованы регистрация, профили пользователей, поиск, объявления и другие функции сайта.
3. **HTML** — для создания структуры веб-страниц.
4. **CSS** — для оформления сайта и адаптации интерфейса под компьютеры и смартфоны.
5. **JavaScript** — для интерактивных элементов, например фильтров поиска, лайков и откликов на объявления.
6. **SQLite** — реляционная база данных, которую мы планируем использовать на этапе разработки. При размещении сайта на хостинге возможен переход на PostgreSQL.
7. **Git и GitHub** — для хранения исходного кода, отслеживания изменений и совместной работы над проектом.
8. **Visual Studio Code** — среда для написания и редактирования кода.

**База данных**

В базе данных будут храниться аккаунты пользователей, информация из анкет, интересы, цели знакомства, лайки, блокировки, поисковые запросы и отклики на них.

Для этого мы планируем создать связанные таблицы, например:

- `Users` — данные пользователей.
- `Profiles` — информация из анкет.
- `Likes` — отметки симпатии.
- `SearchPreferences` — цели и настройки поиска.
- `Requests` — объявления о поиске напарников.
- `Responses` — отклики на объявления.
- `Reports` — жалобы на пользователей.

**Распределение работы**

Лобачева Варвара будет заниматься моделями аккаунтов, профилей, лайков, блокировок и жалоб.

Гусева Лидия будет разрабатывать модели поисковых настроек, объявлений и откликов, а также алгоритм поиска и рекомендаций.

Структуру общей базы данных и взаимодействие между её частями мы будем проектировать совместно.
